04 / 05

PROJECTS

Three builds in three languages, all aimed at the same question: how do systems behave when money, speed and incentives collide?

RUST

LightTime

A concurrent distributed ledger designed to neutralize capital-concentration exploits.

  • Sub-linear mining curves (√x): returns grow with the square root of input instead of linearly, which blunts the advantage of concentrated capital.
  • Sequential VDF locks: verifiable delay functions force work to happen in order, so it cannot simply be parallelised away with more hardware.
  • Concurrent by design: built in Rust for safe parallelism across the network.

JULIA

Figgie-Analysis

A 1:1 double-auction simulator of Figgie, the card game from Jane Street.

  • Double auction: bids and offers match like they would on a real exchange.
  • Hand-rolled Markov chains: the state models are written from scratch rather than pulled from a library.
  • The goal: isolate systemic tail-risk anomalies in zero-sum markets.

OCAML

JaneStreet-lite

A low-latency, high-frequency trading infrastructure prototype.

  • Deterministic matching engine: the same inputs always produce the same trades, so runs can be replayed and tested.
  • Atomic pre-trade risk engine: risk checks and updates happen as one indivisible step before an order reaches the book.
  • Built for speed: designed around low latency from the start.
